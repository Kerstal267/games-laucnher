

# 🎮 Simple Game Launcher (Tkinter)

Простой GUI-лаунчер для запуска игр/программ, написанный на Python с использованием `tkinter`.

Позволяет:

* ➕ добавлять игры
* ▶ запускать их
* ❗ удалять из списка
* 💾 сохранять список между запусками

---

## 🚀 Возможности

* Графический интерфейс (Tkinter)
* Сохранение списка игр в `JSON`
* Выбор файлов через проводник
* Запуск программ через `subprocess`
* Простой и понятный код (идеально для обучения)

---

## 📦 Установка

### 1. Убедись, что установлен Python

```bash
python --version
```

Требуется Python 3.7+

### 2. Склонируй репозиторий

```bash
git clone https://github.com/your-username/simple-launcher.git
cd simple-launcher
```

### 3. Запусти программу

```bash
python main.py
```

---

## 🖥️ Интерфейс

* **МОІ ІГРИ** — список добавленных игр
* **➕ Додати гру** — добавить новую игру/программу
* **▶ Грати** — запустить выбранную игру
* **❗ Видалити** — удалить игру из списка

---

## 📂 Как это работает

### Добавление игры

1. Нажми **"Додати гру"**
2. Выбери `.exe` или любую программу
3. Она появится в списке

### Запуск игры

1. Выбери игру в списке
2. Нажми **"Грати"**

### Удаление игры

1. Выбери игру
2. Нажми **"Видалити"**
3. Подтверди действие

---

## 💾 Хранение данных

Все игры сохраняются в файл:

```
games_simple.json
```

Пример структуры:

```json
[
  {
    "name": "game.exe",
    "path": "C:/Games/game.exe"
  }
]
```

---

## 🧠 Архитектура

Основной класс:

```python
class SimpleLauncher
```

### Ключевые методы:

| Метод           | Описание          |
| --------------- | ----------------- |
| `create_ui()`   | Создает интерфейс |
| `add_game()`    | Добавляет игру    |
| `play_game()`   | Запускает игру    |
| `delete_game()` | Удаляет игру      |
| `save_games()`  | Сохраняет в JSON  |
| `load_games()`  | Загружает из JSON |



## ⚙️ Используемые библиотеки

* `tkinter` — GUI
* `json` — хранение данных
* `os` — работа с путями
* `subprocess` — запуск программ
